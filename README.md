# 叽里咕噜 SpeakEasy

**把“话到嘴边说不出来”的时刻，变成一次英语口语练习。**

有时我们明明知道自己想说什么，却一时想不到自然的英语表达。叽里咕噜希望接住这样的瞬间：输入或说出脑海里的中文，看看它可以怎样用英语自然地表达。每一次卡壳，都能顺手练习一次；练得多了，下次就更有可能直接用英语说出来。

## 功能

- 输入中文，获取三种日常英语表达，以及中文说明和简短例句
- 使用中文语音识别输入想表达的内容
- 播放英语表达的英式英语语音
- 点选表达中的单词，查看音标和常见中文释义
- 收藏喜欢的表达，保存练习记录
- 自定义回复偏好，并选择浅色、深色或跟随系统外观

## 运行环境

- iOS 17 或更新版本
- Xcode
- DeepSeek API Key

## 运行项目

1. 使用 Xcode 打开 `SpeakEasy.xcodeproj`。
2. 选择 iPhone 或 iPad 模拟器，或连接的设备，然后运行 `SpeakEasy`。
3. 语音输入需要允许麦克风和语音识别权限；AI 表达生成和单词查询需要 DeepSeek API Key。

> 当前版本尚未提供在 App 内配置 API Key 的入口，因此新安装后暂时无法直接使用 AI 表达生成和单词查询。

## 隐私说明

练习内容和单词查询会发送至 DeepSeek 以生成结果。练习记录、收藏内容和偏好设置保存在设备本地。请勿将 API Key 提交到公开仓库。

## 项目初衷

英语口语的进步，来自一次次真实的表达。与其等到准备充分才开口，不如从每一次“我想说，但不知道怎么说”开始练习。叽里咕噜想让这些时刻变成轻松、自然、随手可做的口语练习。
